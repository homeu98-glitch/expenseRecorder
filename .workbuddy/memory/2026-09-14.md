## 落地實作：官網首頁正式上線（app/homepage/）

**用戶指示**：配色 OK、可以 commit 上 Vercel；但**要把設計註解全部拿走**（「那些不應該存在」）。

**做法：把確認稿的設計直接搬成頁面，唔需要用 Tailwind 重寫**
- `app/homepage/homepage.css`（565 行）—— 由確認稿的 `<style>` 用 node 腳本轉出：
  移除 `.reviewbar` / `.stage` / `.canvas` / `.anno`、`body{}` → `.hp-root{}`、
  **全部 class 加 `hp-` 前綴**（避免同 `globals.css` 嘅 `.card`、Tailwind 撞名）
- `app/homepage/page.tsx` —— 15 個區塊，資料驅動（陣列 + `map`），業態分頁用 `useState`

**為何用獨立 CSS 而唔係 Tailwind utility**：設計已有完整 CSS，硬翻成 utility
工作量大又易走樣。加 `hp-` 前綴的獨立 CSS 可保證視覺 100% 一致。

   （`width:100vw;left:50%;margin-left:-50vw`）突破
3. `.hp-sec` 要帶 `padding:76px 0`，但 nav / hero 要例外（用 `.hp-sec.hp-nav` 更高特異性覆蓋）
4. `HOVER_RE` 原本寫 `\b(hp-card|…|hp-strip)\b` → **永遠唔匹配** `.hp-cust-strip`

**🔴 落地時最關鍵嘅一個坑**：`.hp-root` 原本只有 `overflow-x:clip`，
佢會**裁切**子元素 `.hp-bleed` 的全寬突破（截圖見到標題左邊被切、兩側露出 body 底色）。
→ 修法：**容器自己都要滿寬**
```css
.hp-root{ width:100vw; margin-left:calc(50% - 50vw); overflow-x:clip; }
```
（`calc(50% - 50vw)` 令容器由 viewport 左邊 x=0 開始，同時 `clip` 繼續防滾動）
