### ✅ 真兇找到了：Vercel 部署處於「Staged」狀態

**更正上一節的推論**：sigma **確實係本專案的 Production domain**
（Settings → Domains 顯示 `expense-recorder-sigma.vercel.app` = Production, Valid Configuration）。

**真正原因**（Vercel 官方定義的 production 部署三態）：

| 狀態 | 意思 |
|---|---|
| **Staged** | commit 推到 main，但**冇 domain 被自動指派** |
| Promoted | 由 staging promote 上嚟 |
| Current | 已 alias 到 domain，正在服務用戶 ← 呢個先係「上線」 |

截圖顯示部署 Detail 的 Environment = `Production` + **`Staged`**，
而且該部署的 Domains 列表**只有 3 個 `-homeu98-9676s-projects` 網域，冇 sigma** →
部署根本未接管 production domain。

**成因**：專案關掉了 **Auto-assign Custom Production Domains**
（Settings → Environments → Production → Branch Tracking）。

**解法**
1. 立即：Deployments → 揀該部署 → `...` → **Promote to Production**（唔使 rebuild，即時生效）
2. 長遠：重新開啟 Settings → Environments → Production → Branch Tracking 的
   **Auto-assign Custom Production Domains**，之後 push 就自動上線
3. 偏方（社群實測）：去 Settings → Domains 直接按 **Save**（唔改任何嘢），有機會刷新 domain 狀態

**同時更正**：之前見到 `-homeu98-9676s-projects.vercel.app` 要登入，
係因為佢係**非 production 的部署網址**受 Standard Protection 保護；
**production domain（sigma）本身係公開的**（實測 200）→ 客人唔會撞到登入頁。
